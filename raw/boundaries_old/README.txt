Older region/district boundaries matching the WFP, Cadre Harmonise and rainfall data.
Source: geoBoundaries (gbOpen), https://www.geoboundaries.org  - licence CC BY 4.0
  Mali ADM1 (9 old regions, year 2021), Mali ADM2 (50 cercles, 2017)  - source DNCT / OCHA Mali
  Burkina Faso ADM1 (13 old regions, 2017), ADM2 (45 provinces, 2017) - source World Bank
Each level comes as full detail and *_simplified.geojson (smaller, better for D3 web maps).
Properties: shapeName (region name), shapeISO (ISO code, e.g. ML-1, BF-01), shapeID.
Notes:
 - Mali "Koulikouro" in geoBoundaries = "Koulikoro" elsewhere (spelling).
 - No HDX p-codes in these files: join by normalised name via the region lookup table.
 - Checked 24 Oct 2026: all WFP markets (Mali 242, Burkina Faso 67) fall inside the region their admin1 name says.
 - UCDP Mali events labelled "Menaka region" fall inside old Gao region (245 events, 2015-2024).
Use the newer files in ../boundaries for Niger, Chad and Senegal (they match the data).
